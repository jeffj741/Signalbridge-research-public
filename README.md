# SignalBridge Labs — Public Research Workbench

An interactive, browser-based exhibit exploring how event trajectories, recovery timing, and population variation can be inspected through a synthetic research instrument.

## Open the exhibit

After GitHub Pages is enabled, visit: https://jeffj741.github.io/Signalbridge-research-public/

## What visitors can explore

- 72 deterministic **illustrative** synthetic observations in three descriptive clusters
- Population projection, recovery comparison, and outlier-distance views
- Keyboard-accessible observation selection and nearest-signature exploration
- An explicit research interpretation boundary

## Scientific and privacy boundary

This is a public-facing **interface demonstration**, not a reproduction of the original frozen PressureIQ Event Arc experiment. The observations and metrics are generated examples, not participant records or validated physiological outcomes. No personal data, original research payload, proprietary methods, or hidden fields are included. The exhibit does not demonstrate clinical efficacy.

The canonical SignalBridge Labs logo has not been included pending an approved asset.

## Hosting

This is a static site with no build step. In GitHub repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save. Publication can take a few minutes.
